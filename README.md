# Fridge Roast: One Line, Biggest Laugh

A make.fun bounty entry. `main.py` (Python 3.13, stdlib only) writes a single
roast line about a smart fridge to `/output/entry.txt`.

## The roast

> My smart fridge spent twenty minutes updating its firmware to tell me the ice maker is 'temporarily unavailable' — since 2019.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
